## 1. 一句话

**一个能真用起来的待办清单**：说一句就自动填好、打开就知道先干什么，工作和生活分开管理，
隔天还会给你一句**俏皮但实在**的复盘。

V0.3 起多了一样本事——**云同步**：填一个服务地址 + 密钥 + 同步口令，手机和电脑的数据就通了；
**不配也完全照常**，它只是个可选外挂，后端挂了、断网了，App 一切功能不受影响。

数据默认存在你自己的设备上，网页和手机 App 是**同一套代码**，功能完全一致。

## 2. 怎么打开

| 平台 | 怎么做 |
|---|---|
| **电脑** | 双击 `prototype/index.html`，用 Chrome / Edge |
| **安卓手机** | 安装 `待办清单-V0.3.apk`（版本号 0.3 / versionCode 3），首次需授权一次"未知来源" |

**不需要账号、不需要备案、不花一分钱。** 不联网也能用（解析走本机规则，复盘留位不放假文案）。

## 3. 界面导览

底部三栏，打开默认落在第 ① 栏；**顶部是固定的「工作 / 生活」切换器**。

| 位置 | 内容 |
|---|---|
| **顶部固定栏** | 工作 / 生活切换器——**不随页面滚动消失**，随时可点；配色与数据整站跟着变 |
| **① 记一笔** | 输入框（打开即聚焦、键盘自动弹出），下方「逾期 + 今天」 |
| **② 日历** | 月历可翻月；点某天看当天明细（含当天复盘） |
| **③ 我的** | 云同步、AI 服务配置、数据与备份、回收站、自定义背景图、分类管理、检查更新 |

说明：第 ③ 栏的切换器是**灰色静态态**（设置与域无关，不可点）——这是产品规则，不是坏了。

**真机适配（APK）**：全屏撑满、自动避开手机真实状态栏和底部手势条、状态栏图标自动用深色
（白底白字的问题已修）、打开时键盘自动弹出、大小手机（320~480px 宽）都不变形。

## 4. V0.3 新增了什么（对比 V0.2）

| 新增 | 一句话 |
|---|---|
| **云同步（三种后端）** | 本地试用服务器 / Supabase / 腾讯云 COS，都是「填地址 + 密钥 + 同步口令」的自带后端模式 |
| **同步口令与空间** | 口令在本机算出空间 ID（PBKDF2 十万次），**口令本身永不上云**；换口令 = 换一个空间 |
| **自动同步 + 离线补传** | 打开 App、每次改动后自动同步；断网时改动留本机，联网自动补传，不丢不重 |
| **冲突处理** | 以修改时间更晚的为准；双方都改过 → **弹窗二选一，绝不默认覆盖** |
| **配置码换设备** | 一台【导出配置码】→ 另一台【导入配置码】，地址/密钥/口令一次搬过去 |
| **状态可见** | 「我的」页一行小字：已连接 / 上次同步时间 / 待补传 N 条 / 未配置 |
| **真机全屏适配** | 原型网页 → 真机形态：全屏拉伸、状态栏避让、键盘自弹、深浅图标、多分辨率 |
| **凌晨解析特例** | 凌晨 0~4 点说「明天/明早/明晚」按**当天**算（半夜记待办的实际用法） |
| **提示词升 V0.3** | 解析规则补凌晨特例，定稿文档改名 `V0.3-提示词-已定稿.md` |

## 5. 功能清单

### 记一笔

- 打开即聚焦、键盘自动弹出，可直接打字；语音用**输入法自带的麦克风**
- 点右侧 **【✦】** → 展开 5 行：标题 / 完成时间 / 轻重缓急 / 归属 / 分类
- **归属自动填好**；每一行都能点着改，改过的行出现灰色「**手填**」角标，再解析也不会被覆盖
- 三条路径都行：① 直接【保存】② ✦ 解析后保存 ③ 手工填完保存
- **填不全也没关系** —— 4 项没填全就进收件箱，绝不丢

### 解析能听懂什么

接了 AI 之后是**大模型在理解**，本机规则版兜底：

| 类型 | 例子 |
|---|---|
| 日期 | 今天 / 明天 / 后天 / 下周 / 下个月 / 18 号 / 下周三 |
| 时间 | `3点`、`下午3点`、`晚上8点`、`9点半`、`4点45` |
| 重要 | 「重要 / 关键 / 老板要看 / 考核 / 必须 / 要紧」 |
| 紧急 | 「急 / 尽快 / 马上 / 催 / 赶紧 / 临时 / 截止」 |
| 分类 | 只从当前域已有分类里挑，**不自造** |

两条特殊规则：

- **没提到的 = 不算**，不擅自判重要/紧急；
- **凌晨 0~4 点**说「明天/明早/明晚」= **当天**（「后天」= +1 天）；04:00 起按字面。
  AI 提示词和本机规则**同口径**，没网时也不会算错一天。

### 四象限（轻重缓急）

真正的数学象限，两条轴从四格中间的缝隙穿过；四格常带颜色，点一格就选中。
列表里**只显示颜色、不写字**；存进库的仍是「重要 / 紧急」两个值。

| 颜色 | 含义 |
|---|---|
| 🔴 红 | 重要且紧急 · 马上做 |
| 🔵 蓝 | 重要不紧急 · 计划做 |
| 🟠 橙 | 紧急不重要 · 快速处理 |
| ⚪ 灰 | 不紧急不重要 · 有空再说 |

### 列表与手势

- **点条目 = 进详情页**；**点最左边小圆圈 = 标完成**（不跳转）
- 完成后整条转灰、加删除线、排到当天最下面，显示**真实完成时刻**
- 排序：**置顶 → 逾期（组内按象限）→ 四象限 → 已完成**
- 首屏**不折叠**，放不下就下滑；点任何选项都不会被弹回顶部

### 每日复盘

- **归属"上一天"**：今天干的事，明天打开才看到总结
- 工作 + 生活合并的**一句话**，两个域看到的逐字相同
- 语气是**会损你的老朋友**：能吐槽、能调侃，只冲事不冲人
- **生成后锁定**，只有点【重新生成】才重算；一天没动静 → 不生成
- AI 失败 → 标"待生成"，下次打开自动重试，**不弹窗打扰**

### 日历

- 可翻月，今天有标记；每格 `3●2○`：● 已完成、○ 未完成
- **红下划线** = 这天有逾期；**灰底** = 这天有复盘
- 点某天进明细区，顶部就是那天的复盘（含统计与生成时间）
- 每个月的行都与表头「一~日」对齐（首尾不足 7 格用空白补满）

### 收件箱

- **跨域暂存区**，两个域右下角各一个入口，进的是同一个
- 补完 4 项点【保存】即归入某域；可一键重新解析；**手填字段不被覆盖**
- 标题没填但有备注时，保存用**备注前 12 字**当标题

### 分类

- 工作、生活各 4 个，可新建（名称 / 颜色 / 符号）
- **长按可拖动排序**，拖动时画出插入位置横线
- **删分类不删待办**，改为「未分类」

### 数据与备份（第 ③ 栏）

| 操作 | 说明 |
|---|---|
| **导出全部数据** | 一次出两个文件：`.json`（完整备份，能导回）+ `.csv`（Excel 直接打开，中文不乱码） |
| **导入备份** | 选导出的 `.json`，**合并**（同条目以更晚修改为准）或**覆盖** |
| **自动备份** | 每次打开自动写一份当天快照，保留 30 天，可查看可导出 |

导出到哪儿：手机 → `文件管理 / 下载 / 待办清单`；电脑 → 浏览器默认下载目录。
**所有导出文件都不含 API Key 与云密钥。**

### AI 服务配置（第 ③ 栏）

选服务商（DeepSeek 推荐 / Kimi / OpenAI / 自定义）→ 地址和模型自动填好 → 只贴 Key →
【拉取模型列表】挑一个 →【测试连接】（一次真实调用）→ 保存。
实测：**DeepSeek 网页直连可用**；**Kimi 浏览器里连不上**（手机 App 里可以）。

### 云同步（第 ③ 栏，V0.3 新增）

**三种后端，任选一种**（都是「填地址 + 密钥 + 同步口令」的自带后端模式）：

| 后端 | 适合谁 | 怎么起步 |
|---|---|---|
| **本地试用服务器** | 先在本机把链路跑通的人 | 双击 `tools/start-sync-server.bat`，地址填 `http://127.0.0.1:8787` |
| **Supabase** | 想免费上云的人 | 免费项目 + 一段建表 SQL，地址填项目 URL、密钥填 publishable key |
| **腾讯云 COS** | 国内直连最快的人 | 私有桶 + CORS + 子账号密钥（免费额度个人用不完） |

**配法（一次一分钟）**：我的 → ☁️ 云同步 → 填地址 / 密钥 / 同步口令 →【测试连接】→ 保存。
详细图文见 `docs/V0.3-云同步怎么用.md` 和 `docs/腾讯云COS怎么用.md`。

行为规则：

- **口令不上云**：本机用 PBKDF2 把口令算成空间 ID，不同口令互相看不到
- **自动同步**：打开 App、每次改动后自动进行；「我的」页一行小字看状态
- **冲突**：修改时间更晚的赢；双方都改过 → **弹窗二选一，绝不默认覆盖**
- **断网**：改动留在本机待传队列，联网自动补传
- **云端只存一个 JSON**（你的整包快照），**不存 API Key 等任何密钥**
- **配置码**：【导出配置码】→ 另一台【导入配置码】，地址/密钥/口令一次搬完
  （导出时会弹窗提醒"这个码等于钥匙，别发群里、别存网盘"）
- **挂了也不怕**：没配 / 断网 / 后端故障 → App 照常用，只不同步，不弹错不卡死

## 7. 已知限制

1. **数据默认只在本机**：换设备用导出导入，或按第 5 节配云同步
2. **整包快照 = 最后写入胜出**：多设备**同时**编辑会互相覆盖（冲突时弹窗让你选）；逐字段合并留到以后
3. **免费后端长期不动可能被暂停**：去后台点一下恢复即可，暂停期间 App 照常用
4. **Kimi 在浏览器里连不上**（跨域限制），手机上正常
5. **清空数据**：电脑在浏览器设置里清除站点数据；手机卸载 App 会一并清掉（先导出！）
6. 手机上最低支持**安卓 10**
