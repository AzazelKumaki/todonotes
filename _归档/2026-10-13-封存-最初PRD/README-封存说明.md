## 为什么封存

最初的 PRD 从 v1.3 一路迭代到 v2.8，累计 170KB / 1100+ 行，41 条需求 + 25 条待拍板项。
它已经完成了使命：**把产品想清楚**。但它不再适合当开发手册 —— 太长，且其中大量需求属于 M2 之后。

截至 2026-10-13，**M1（V0.1）已开发完成**，11 项待拍板项已拍板、7 处规则变更已回写。
此后开发以 `docs/PRD-M1-V0.1.md` 为准，这份完整版转为**历史决策档案**。

- **实现盘点里的行号只对 M1 改造前的 `prototype/index.html` 有效**。M1 已重写逻辑层，行号全部失效。
- **PRD v2.8 的 §0.8 是最后一次规则变更记录**（排序逾期优先、入箱 4 项判定、四象限选择器等），这些已并入新 PRD 的「硬规则清单」。

## 恢复方式

需要继续做 M2 时，从 `PRD-最初完整版-v2.8-已封存.md` 里把对应需求抄进新版 PRD，
并**按 M1 已拍板的硬规则调整口径**（尤其是排序、入箱判定、四象限三处）。
