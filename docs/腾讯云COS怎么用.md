# 腾讯云 COS 怎么用（云同步后端）

> 一篇从零到能用。按顺序做，全程在网页上点，不用写代码、不用买服务器。
> 做完以后，App 里「我的 → ☁️ 云同步」选 **腾讯云 COS**，填四个框就能同步。

---

## 零、先说清楚要花多少钱

腾讯云对象存储**每月有免费额度**：

| 项目 | 免费额度 | 你的用量 |
|---|---|---|
| 存储空间 | 50 GB | 你的数据几十 KB |
| 外网下行流量 | 10 GB/月 | 一个月几百 KB |
| 读请求 | 100 万次/月 | 一个月几千次 |
| 写请求 | 10 万次/月 | 一个月几千次 |

**结论：正常用不会花一分钱。** 就算哪天超了，超出部分也就几分钱级别（存储 ¥0.13/GB·月、请求 ¥0.01/万次）。

---

## 一、注册与实名（约 5 分钟）

1. 打开 https://cloud.tencent.com ，用**手机号**注册一个腾讯云账号
2. 按提示完成**实名认证**（个人实名：填姓名 + 身份证号，一般几分钟就过）
3. 手机号和实名是必须的——这是国内云服务的规定，跳过后面都做不了

> 我没办法替你注册：它绑的是你的手机号和身份信息。注册这一步只能你自己来，后面的操作说明我都写好了。

---

## 二、开通对象存储、建一个桶

1. 登录后搜索 **对象存储**（或直接打开 https://console.cloud.tencent.com/cos ）
2. 第一次进去会让你**开通服务**，点开通（免费，不用选套餐）
3. 左侧「存储桶列表」→ **创建存储桶**：

| 填什么 | 怎么填 |
|---|---|
| 名称 | 自己起，比如 `daiban`（系统会自动加一串数字） |
| 地域 | **选离你最近的**，比如广州 / 上海。⚠️ 记住选了哪个，App 里要选一样的 |
| 访问权限 | 选 **私有读写** |
| 其他 | 都默认 |

4. 建好后，列表里会显示完整桶名，形如 **`daiban-1250000000`**
   → **这串后面带数字的全名要原样填进 App**，只填 `daiban` 是不行的

---

## 三、配跨域（CORS）—— **这一步漏了就一定连不上**

我们的 App 是浏览器环境（手机 App 也是），跨域必须服务端点头。

1. 点进你的桶 → 左侧 **安全管理 → 跨域访问 CORS 设置**
2. 点 **新增规则**，照这个填：

| 项 | 填什么 |
|---|---|
| 来源 Origin | `*` |
| 操作 Methods | 勾选 **GET、PUT、HEAD** |
| Allow-Headers | `*` |
| Expose-Headers | `ETag` |
| 超时 Max-Age | `600` |

3. 保存。**改完大约 1~2 分钟生效**，急的话等一下再测。

---

## 四、拿密钥（建议用子账号，别用主账号）

⚠️ **主账号的密钥权限太大**（能操作你名下所有云资源），而 App 是可以被反编译的。**强烈建议建一个子账号，只给它这一个桶的权限。**

### 4.1 建子账号
1. 打开 https://console.cloud.tencent.com/cam → **用户 → 用户列表 → 新建用户**
2. 创建方式选 **快速创建**，类型选 **编程访问**（不用勾选控制台访问）
3. 用户名随便起，比如 `daiban-sync`
4. 建好后，页面会给你 **SecretId** 和 **SecretKey** —— **立刻复制保存**（SecretKey 只显示一次）

### 4.2 给它限定到这一个桶
1. 左侧 **策略 → 新建自定义策略 → 按策略语法创建**
2. 策略名随便起，内容粘贴下面这段（**把两处数字换成你的**）：

```json
{
  "version": "2.0",
  "statement": [
    {
      "effect": "allow",
      "action": ["cos:GetObject", "cos:PutObject", "cos:HeadObject"],
      "resource": ["qcs::cos:ap-guangzhou:uid/1250000000:daiban-1250000000/*"]
    }
  ]
}
```

- `ap-guangzhou` → 换成你建桶时选的地域（上海是 `ap-shanghai`，北京 `ap-beijing`）
- `1250000000` → 换成你的 **APPID**（控制台右上角账号信息里能看到，就是桶名后面那串数字）
- `daiban-1250000000` → 换成你的完整桶名

3. 保存策略 → 回到 **用户列表 → 点刚才那个用户 → 关联策略** → 勾上刚建的策略

---

## 五、回到 App 里填

「我的 → ☁️ 云同步」→ 服务商选 **腾讯云 COS** → 填四样：

| 框 | 填什么 | 例子 |
|---|---|---|
| 存储桶名称 | **完整桶名**（带数字） | `daiban-1250000000` |
| 地域 | 跟你建桶时选的一样 | 广州 |
| SecretId | 上一步拿到的 | `AKIDxxxxxxxx...` |
| SecretKey | 上一步拿到的 | `xxxxxxxx...` |
| 同步口令 | **自己起一个**，两台设备填一样的 | 随便想一句 |

点【测试连接】→ 显示"连接成功"→【保存并开启】。

> **同步口令**不会被上传，它只在你本机算成一个 ID（256 位），云端只存这个算出来的串。忘了口令 = 这份云端数据找不回来（本机数据不受影响）。

### 第二台设备
第一台【导出配置码】→ 第二台【导入配置码】粘进去 → 自动测连通并开启。
⚠️ 配置码里含密钥，等于钥匙，别发群、别存网盘。

---

## 六、连不上看这里

| 现象 | 原因 | 怎么办 |
|---|---|---|
| **域名解析不到** | 桶名抄错了 | 一定要带后面那串数字；地域也要对 |
| **403 被拒** | ① CORS 没配 ② 密钥没权限 ③ 用的是主账号 SecretId 但策略没绑 | 按第三节重配 CORS，等 2 分钟；确认子账号绑了策略 |
| 连到一半断了 | 本机网络问题 | 换网络试试 |
| 报"证书校验没过" | 系统时间不准 | 把系统时间同步一下 |
| 一直是"没连上"但没报错 | 可能规则刚改还没生效 | 等 2 分钟，再点【测试连接】 |

**任何失败都不影响你用 App** —— 数据都在本机，只是不同步。

---

## 七、安全上要记住的两条

1. **别用主账号密钥**（权限覆盖你所有云资源），用第四节那种限定单桶的子账号
2. 桶保持**私有读写**；我们靠"口令派生的 ID 不可猜"来隔离，不靠桶的公开性
