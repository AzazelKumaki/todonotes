## 1. 先记住三句话

1. **说一句话就能记下来**：在输入框写「明天下午三点前把周报交给王总」，点右边的 ✦，它就自己变成一条待办。
2. **点圆圈 = 完成，点条目 = 详情**，两件事互不干扰。
3. **不联网、不注册、不花钱**。数据存在你自己设备上。联网只是锦上添花（同步、AI）。

## 2. 怎么打开

| 平台 | 怎么做 |
|---|---|
| **电脑 / 平板** | 双击 `index.html`，用 Chrome 或 Edge 打开。窗口够宽（≥900px）会自动切成**桌面布局并铺满整个窗口**：左边固定着「工作 / 生活」切换器和三个栏目，右边是内容区；窗口拉窄到 900px 以下就变回手机的样子（同样铺满） |
| **安卓手机** | 安装 APK（版本号 0.5）。首次安装需要给一次「未知来源」授权 |

网页和手机 App 是**同一套东西**，功能一模一样。
手机上第一次安装，系统会问一次「允许安装未知应用」，给一次就行 —— 除此之外 App 不向你要任何权限。

## 3. 第一次用：三步记下第一件事

打开就是输入框，光标已经在里面闪（手机上键盘会自动弹出来）。

| 步骤 | 你要做的 | 会看到什么 |
|---|---|---|
| ① | 写一句话，比如「下周三之前把年报初稿发给李经理」 | 输入框里是你的原话 |
| ② | 点输入框右边的 **✦** | 下面展开五行：**标题 / 完成时间 / 轻重缓急 / 归属 / 分类**，已经自动填好了 |
| ③ | 点 **保存** | 这条出现在下面的列表里 |

> **✦ 是做什么的？**
> 它把一句大白话拆成结构化的字段。拆错了不要紧 —— **每一行都能点**，点开就能自己改。
> 改过的字段会挂一个小标记「手填」，意思是下次再解析也不许改你的。

**不想用 ✦ 也行**：直接点【保存】，它会原封不动躺进右下角的**收件箱**，等你有空再补字段。

### 退出输入状态
点【返回】· 点输入框外面任意处 · 按 `Esc`。这三种都行，没保存的内容不会丢（输入框里的字还在）。

## 4. 界面导览

顶部一条固定栏是 **工作 / 生活** 切换器（不随页面滚动消失）；底部三栏：

| | 叫什么 | 里面有什么 |
|---|---|---|
| **①** | 记一笔 | 输入框、**逾期**的事项、今天要做的事 |
| **②** | 日历 | 月历、筛选、**循环安排** |
| **③** | 我的 | 云同步、AI 配置、数据与备份、回收站、换配色、分类管理、检查更新 |

> 第 ③ 栏顶部的「工作 / 生活」是**灰的、不可点** —— 设置跟域无关，这是设计如此，不是坏了。

右下角那个**圆形按钮是收件箱**（带一个数字，就是还没整理的原话有几条）。

## 5. 每一件事怎么看懂

### 5.1 左边那条彩色竖线 = 轻重缓急

| 颜色 | 意思 | 什么时候用 |
|---|---|---|
| <span style="color:#DC2626">■ 红</span> | **马上做**（重要 + 紧急） | 今天必须交的东西 |
| <span style="color:#2563EB">■ 蓝</span> | **计划做**（重要，不急） | 提前铺排的事 |
| <span style="color:#F59E0B">■ 橙</span> | **快速处理**（紧急，不重要） | 别人催着要的小事 |
| <span style="color:#94A3B8">■ 灰</span> | **有空再说**（都不占） | 顺手再碰的事 |

> 颜色**不绑定具体哪天** —— 它是你对这件事的判断，不是倒计时。
> 而且规矩是：**你不说「重要」「催」「尽快」这类词，它就一律按「有空再说」**，绝不替你紧张。

### 5.2 列表怎么排的

置顶的 → **逾期的**（内部只按轻重缓急）→ 其余**按时间先后**排 → 同一时间再按轻重缓急 → 完成的沉到最下面。

完成的事**不会消失**，整条变灰、划掉，沉到当天最底部 —— 留着给你看今天干了什么。

### 5.3 每一行的副标题在说什么

- 「逾期 3 天」红了就是拖了三天
- 「15:00」「10月18日」就是原定时间
- 完成了显示「完成于 10月15日 22:31」—— 那是**你真实点完成的时刻**
- 开头有个 🔁 = 这条是**会重复**的，标完成后会自动排下一次（暂停了就不显示）

### 5.4 一次弄好几件（批量）

**长按**列表里的任意一条（手指按住别动，约半秒），就进入多选：

| 位置 | 有什么 |
|---|---|
| 列表顶上 | `已选 N 条` · 【全选】· 【取消】（往上翻的时候它一直吸在顶上） |
| 屏幕底边 | 四个动作：**标完成** · **改分类** · **顺延明天** · **删除** |

- 再点别的条目 = 加选 / 取消选它；**【取消】、按 `Esc`、或点列表空白处**都能退出
- 删掉的是进**回收站**（30 天内可恢复），不是真没了
- 【顺延明天】只把日期往后挪一天，**时刻不变**
- 【改分类】只对当前归属（工作或生活）下的那些生效 —— 挂在另一边的不动
- 已经在多选了，左边的小圆圈就不再是「标完成」，而是「选中」

> 分类管理里也有长按，那是**拖动排序** —— 两条规矩互不干扰：那里是「按住 + 拖动」，这里是「按住不动」。

## 6. 日历（第 ② 栏）

| 格子里的东西 | 意思 |
|---|---|
| `3●2○` | 这天安排了 5 件：**3 件已完成、2 件还没做** |
| 格子底下一条**红线** | 这天有逾期没做的事 |
| 格子**灰底** | 这天写好了总结 |

- 左右箭头翻月
- **点某一天** → 打开当天明细，最上面是那天的总结一句话
- 点【筛选】可以按关键词、轻重缓急、分类、状态找某一件事（可切换「只看本月 / 全部」）

### 循环安排（每周 / 每月 / 每隔几天）
日历页那个 **🔁 循环安排**：填一个名字（比如「周会」），选每周几 / 每月几号 / 每隔几天，它会一次给你排好接下来三次。

从那以后**不用再手动排**：标完成一次，它就自动把下一次排出来（做过的那条留着不删，方便回看）。

| 想干什么 | 去哪儿 |
|---|---|
| 暂停（先别排了，但规矩留着） | 点开这条 → 「重复」那一栏 → 【暂停】 |
| 继续 | 同一处 → 【继续】 |
| 彻底不重复了 | 同一处 → 【不再重复】（这条就变回普通待办） |

带 🔁 的就是「还会自动排下一次」；暂停了就不挂这个符号。
每月 31 号碰上 2 月会落在 2 月的最后一天，不会跳过一个月。

## 7. 搜索和筛选

| 位置 | 怎么用 |
|---|---|
| 第 ① 栏，列表上面一行 | 点开：可以打字搜（标题和备注都搜），也可以按轻重缓急 / 分类 / 状态点一下筛 |
| 第 ② 栏，日历上面 | 点【筛选】按钮，弹窗里条件 + 结果一起看 |

两屏的条件**各管各的**，互不干扰。
同一个条件再点一次 = 取消。点框外 = 收起（条件还留着，按钮上会写「筛选中 · N 条」）。

## 8. 第 ③ 栏「我的」，从上到下

### ☁️ 云同步（可选）
想让手机和电脑的数据通起来就配它。要填：服务地址 / 密钥 / 同步口令（自己想一个，**记牢，丢了找不回**）。
填完点【测试连接】，通过了才能开启。

配好之后自动传，**不用点按钮**。没配、断网、后端挂了 —— App 一切照常，只是不同步，不弹错也不卡死。

**另一台怎么配**：这台点【导出配置码】→ 粘到另一台的【导入配置码】里，全部一次带过去。
⚠️ 配置码等于钥匙，别发群、别存网盘。

#### 附：配一次腾讯云 COS（约 10 分钟，只做一次）

用哪家都行；腾讯云的好处是国内快、免费额度用不完。**它不用填地址** —— 地址由
「桶名 + 地域」自动拼出来，App 里可以随时看到拼出来的结果。

| 步骤 | 在腾讯云控制台做什么 | 拿回来填什么 |
|---|---|---|
| ① | 对象存储 → 创建**私有**存储桶，地域挑一个（比如广州） | 完整桶名，形如 `daiban-1250000000`（**后面那串数字要一起**） |
| ② | 桶 → 安全管理 → **跨域访问 CORS**：来源 `*`，方法勾 `GET / PUT / HEAD`，Allow-Headers `*` | — |
| ③ | 访问管理 CAM → 建**子账号**，只给它这个桶的读写权限 | SecretId 和 SecretKey |
| ④ | 回到 App 的云同步页 | 桶名 / 地域 / SecretId / SecretKey，外加一个**同步口令**（自己想，记牢） |

⚠️ 别用主账号的密钥（权限太大），也别把桶设成公有读。
连不上时先看页面下方那行「实际访问」和 HTTP 状态码：404 = 桶名或地域不对，403 = 密钥或权限，
「请求没发出去」= CORS 没配对。

### 🤖 AI 服务配置（可选）
不配也没事 —— 解析走本机规则，一样能用，只是没那么聪明。

要接的话：选服务商（推荐 **DeepSeek**，实测允许网页直连）→ 地址会自动填好 → **只贴你自己的 Key** → 【测试连接】→ 【保存并启用】。

> Kimi 实测不给浏览器跨域许可：**电脑网页里连不上，手机 App 里可以用**。

### 📦 数据与备份
- 【导出全部数据】→ 一次给你两个文件：`.json`（能导回本应用）+ `.csv`（给 Excel 看，中文不乱码）
- 【从 JSON 备份文件导入】→ 可选**合并**（保留现在的并进来）或**覆盖**（清空只留文件里的）
- 文件里**不含任何 Key**

**每天打开时会自动存一份当日快照**，保留 30 天。攒下的快照在【查看已攒下的快照】里能单独导出。

### 🗑️ 回收站
删掉的东西在这里躺 **30 天**，随时能恢复，回到原来的域和分类。到期自动清理。

### 🎨 换配色
八套预设 + 取色器，工作和生活**各一套**，切换时整站配色跟着变。配色只存在本机。

### 🗂️ 分类管理
整行可点编辑（名字 / 颜色 / 符号）、**长按可拖动排序**（排序在选择分类时也生效）。
删除分类**不会删待办**，只是把它们改成「未分类」。

### 🔄 检查更新
点一下会真去远端查版本号。有新版本时给你版本说明 + 更新说明；手机上还能直接【下载并安装】。

## 9. 每天怎么用顺手

早上打开：顶上就是**逾期**的那几件（红字写着「逾期 N 件」），下面是今天要做的事，按时间排好。

要做一件：点它左边的小圆圈，它变灰沉到底下 —— 不用进详情，一下就好。

忘了以前记了什么：日历 > 筛选 > 打字。备注里的是你的原话，所以哪怕当时没写标题也搜得到。

隔天回头看：日历里点那一天，最上面是那天的总结。**总结只对昨天及更早生成** —— 今天的总结要等明天，因为它得先过完这一天。

## 10. 会碰到的问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 点 ✦ 没反应 | 多半是 AI 还没配好。没关系 —— 它会**自动退回本机规则**照样把字段拆出来，只是没那么聪明。toast 会写明是「本机规则解析」 |
| 保存后不在列表里 | 字段没填全，它进**右下角的收件箱**了。点条目 → 点右上角的 ✦ 或手工补 → 【保存】就归类了 |
| 标题显示成我那句话的前 12 个字 | 你当时没写标题，它用备注临时顶替。点标题那一行改一个就行，不改也不影响保存 |
| 一件完成的事跑到了昨天 | 它**挂在自己原定那天**，不会跟着跑到未来。翻回原定日期能看到「完成于 …」 |
| 两边同步出冲突了 | 状态栏会显示「两边都改过」，点进去选以哪边为准。**自动同步绝不偷偷覆盖你的数据** —— 它一定等你拍板 |
| 换了手机，怎么把东西搬过去 | 老设备【导出全部数据】→ 把 `.json` 传给自己 → 新设备【导入】选合并 |
| App 卡住了 / 数据看起来不对 | 关掉重开。每次打开都会自动写一份快照，最坏能从「数据与备份」里捞回来一天前的样子 |

## 11. 它不会做的事（别以为坏了）

- **不会替你判断轻重缓急**：你不说，它就当「有空再说」（产品底线）。
- **不会擅自改动你填过的字段**：你手动填过的行会挂「手填」，再点 ✦ 也不覆盖。
- **不会上传你的口令和密钥**：口令只在你本机算成一个 ID 再发出去。
- **不会因为云服务出问题就卡住**：云挂了只是状态栏一行字。
