## 1. 一句话

**一个能真用起来的待办清单**：说一句就自动填好、打开就知道先干什么，工作和生活分开管理，
隔天还会给你一句**俏皮但实在**的复盘。
数据存在你自己的设备上，网页和手机 App 是**同一套代码**，功能完全一致。

---

## 2. 怎么打开

| 平台 | 怎么做 |
|---|---|
| **电脑** | 双击 `prototype/index.html`（或留档副本 `留档/V0.2-M2/index.html`），用 Chrome / Edge |
| **安卓手机** | 安装 `待办清单-V0.2.apk`（留档目录里也有），首次需授权一次"未知来源" |

**不需要账号、不需要备案、不花一分钱。** 不联网也能用（只是解析会用本机规则代替 AI）。

> 提示：AI 解析需要联网并配置服务商；不配也完全能用，只是"听不懂人话"的程度高一点。

## 3. 界面导览

底部三栏，打开默认落在第 ① 栏：

| 栏 | 内容 |
|---|---|
| **① 记一笔** | 上方输入框（**打开即聚焦**），下方是「逾期 + 今天」 |
| **② 日历** | 月历可翻月；点某天看当天明细（含当天复盘） |
| **③ 我的** | 数据与备份、AI 服务配置、回收站、背景图、分类管理、检查更新 |

顶部是**工作 / 生活切换器**（第 ①② 栏可点，第 ③ 栏灰色不可点 —— 设置与域无关）。

## 5. 功能清单

### 记一笔

- 打开即聚焦，可直接打字；语音用**输入法自带的麦克风**
- 点右侧 **【✦】** → 输入框下方展开 5 行：标题 / 完成时间 / 轻重缓急 / 归属 / 分类
- **归属会自动填好**（工作域就填"工作"，生活域就填"生活"），切换顶部开关也会跟着变
- **每一行都能点着改**；改过的行会出现灰色「**手填**」角标 —— 表示再解析也不会覆盖它
- 三条路径都行：① 直接【保存】② ✦ 解析后保存 ③ 手工填完保存
- **填不全也没关系** —— 4 项没填全就进收件箱，绝不丢

### 解析能听懂什么

接了 AI 之后是**大模型在理解**，本机规则版作为兜底，能听懂：

| 类型 | 例子 |
|---|---|
| 日期 | 今天 / 明天 / 后天 / 下周 / 下个月 / 18 号 / 下周三 |
| 时间 | `3点`、`下午3点`、`晚上8点`、`9点半`、`4点45` |
| 重要 | 「重要 / 关键 / 老板要看 / 考核 / 必须 / 要紧」 |
| 紧急 | 「急 / 尽快 / 马上 / 催 / 赶紧 / 临时 / 截止」 |
| 分类 | 只从当前域已有分类里挑，**不自造** |

**没提到的 = 不算**。不会因为"时间很紧"就擅自判成紧急，也不会因为"事情听起来大"就判成重要。

### 四象限（轻重缓急）

一个真正的数学象限，**两条轴从四格中间的缝隙穿过**：

```
          重要 ↑
            │
 ┌──────────┼──────────┐
 │  计划做  │  马上做  │
 ├──────────┼──────────┤
 │ 有空再说 │ 快速处理 │
 └──────────┼──────────┘
            │
          不重要 ↓
 ← 不急 ───────────── 紧急 →
```

四格**常带颜色**，点一格就选中（选中只多一层描边和一个小对勾）。
列表里**只显示颜色、不写字**；选中后存进库的仍是「重要 / 紧急」两个值。

| 颜色 | 含义 |
|---|---|
| 🔴 红 | 重要且紧急 · 马上做 |
| 🔵 蓝 | 重要不紧急 · 计划做 |
| 🟠 橙 | 紧急不重要 · 快速处理 |
| ⚪ 灰 | 不紧急不重要 · 有空再说 |

### 列表与手势

- **点条目 = 进详情页**；**点最左边小圆圈 = 标完成**（不跳转）
- 完成后整条转灰、加删除线、排到当天最下面，并显示**真实完成时刻**
- 排序：**置顶 → 逾期（内按象限）→ 四象限 → 已完成**
- 首屏**不折叠**，放不下就下滑
- 现在点任何选项都**不会再被弹回顶部**

### 每日复盘

- **归属"上一天"**：今天干的事，明天打开才看到总结（不是实时播报）
- 是**工作 + 生活合并的一句话**，两个域看到的**逐字相同**
- 语气是**会损你的老朋友**：能吐槽、能调侃，但只冲事不冲人
- **生成后锁定**：后来补记不会改写旧文案，只有点【重新生成】才重算
- 一天完全没动静 → **不生成**，也不留空白记录
- AI 失败 → 标"待生成"，下次打开自动重试，**不弹窗打扰**

### 日历

- 可翻月，今天有标记；每格 `3●2○`：● 已完成、○ 未完成
- **红下划线** = 这天有逾期；**灰底** = 这天有复盘
- 点某天进明细区，顶部就是那天的复盘（含统计与生成时间）

### 收件箱

- **跨域暂存区**，工作/生活右下角各一个入口，进的是同一个
- 解析不全的都在这里；补完 4 项点【保存】即归入某域
- 可一键重新解析；**手动填过的字段不会被覆盖**
- 标题没填但有备注时，保存会用**备注前 12 字**当标题（不会卡住不让存）

### 分类

- 工作、生活各 4 个，可新建（名称 / 颜色 / 符号）
- **长按可拖动排序**，拖动时会画出插入位置的横线
- **删分类不删待办**，改为「未分类」

### 数据与备份（第 ③ 栏）

| 操作 | 说明 |
|---|---|
| **导出全部数据** | 一次出两个文件：`.json`（完整备份，能导回）+ `.csv`（Excel 直接打开，中文不乱码） |
| **导入备份** | 选之前导出的 `.json`，可选**合并**（默认，同条目以最后修改更晚的为准）或**覆盖** |
| **自动备份** | 每次打开自动写一份，保留 30 天；在这个页面里能查看和导出某一天 |

**导出到哪儿**：手机 → `文件管理 / 下载 / 待办清单`；电脑 → 浏览器默认下载目录。
**所有导出文件都不含 API Key。**

### AI 服务配置（第 ③ 栏）

1. 选服务商：**DeepSeek（推荐）/ Kimi / OpenAI / 自定义**（内置通道随 V0.3 云服务开放）
2. 接口地址和默认模型会**自动填好**，你只要贴 Key
3. 点【**拉取模型列表**】→ 从下拉里挑这个 Key 真能用的模型，**不用背名字**
4. 点【**测试连接**】→ 是一次**真实调用**，通过了才允许启用

实测结论：**DeepSeek 带不带 `/v1` 都通、允许网页直连**；**Kimi 在浏览器里连不上**（手机 App 里可以）。

## 6. V0.2 不做的事（别以为坏了）

| 不做 | 说明 |
|---|---|
| **云同步 / 多设备** | 现在每台设备各自一份，靠导出导入搬家 → **V0.3** |
| **App 内在线更新** | 【检查更新】目前只显示当前版本，没有接更新源 → **V0.3** |
| **回收站 30 天自动清理** | 目前只有文案，实际不清 |
| **自定义背景图** | 页面在，但【更换图片】只弹提示 |
| **子任务 / 搜索筛选 / 到期提醒** | → **V0.4** |
| **语音转文字** | 用输入法自带的麦克风即可，App 内原生语音在 V0.4 评估 |

## 7. 已知限制

1. **不配 AI 时解析是关键词匹配**，说得太绕会听不懂 —— 听不懂就进收件箱，**不会丢**
2. **数据只在当前这一个浏览器 / 这台手机里**：换设备要用导出导入（V0.3 出云同步）
3. **Kimi 在浏览器里连不上**（跨域限制），手机上正常
4. **清空数据**：电脑在浏览器设置里清除站点数据；手机卸载 App 会一并清掉（先导出！）
5. 手机上最低支持**安卓 10**
