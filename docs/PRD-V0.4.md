## 1. 背景与目标

### 1.1 背景

V0.3（M3）已交付：云同步（三种自带后端）+ 配置码 + 真机全屏适配，13 条硬规则全部保持。
V0.3 PRD 里明确**推迟**到 M4 的项 + 日常使用中暴露的短板，构成本版范围：

- 在线更新（V0.3 FR-310 未做）
- 自定义背景图（FR-312 未做，目前是 stub）**+ 它带来的状态栏图标动态适配**
- 回收站 30 天自动清理（FR-311 未做）
- 云端上传前本地加密（V0.3 §11 Q3 明确"V0.4 再加 AES-GCM"）
- 搜索 / 筛选（M2 手册就列为 V0.4 项）

### 1.2 M4 的三条硬指标

1. **APK 自己知道有没有新版本**：检查 → 下载 → 引导安装，全流程真能用。
2. **背景图真能换**：两个域各一张，存本机不上云；**状态栏图标跟着图片明暗自动切**
   （V0.3 埋的 TODO，本轮兑现）。
3. **云端数据多加一把锁**：上传前用同步口令派生密钥做 AES-GCM 加密，口令不进日志、不进备份。

### 1.3 本地优先（本版产品底线，不可让步）

APK 离线可用、网页双击可用；云同步与加密都只是可选外挂——
加密没开 / 打不开 / 口令忘了，都**不许**阻塞任何本地操作（规则 13 同口径）。

### 1.4 明确不做（避免范围蔓延）

- 子任务、到期提醒（系统通知）、语音转文字 → **V0.5 评估**，本版不碰
- 内置云通道 / 免密钥 AI（FR-313）→ 仍排最后，**发布成网址之后**再评估
- 逐字段合并 → 仍是整包快照 + 冲突弹窗，不动
- 换存储引擎（localStorage → IndexedDB）→ 本版不做（见 §10 R1 的压缩方案兜底）

## 3. 硬规则（继承，冲突时以此为准）

V0.3 的 13 条**原样继承**（排序 / 入箱 4 项 / 存两个显示一个 / 列表不显象限文字 / 手填保护 7 字段 /
首屏不折叠 / 归属只改这条 / 备注逐字保留 / 真实完成时刻 / 删分类改未分类 / AI 可失败降级 /
导出备份不含密钥 / 本地优先）。接口契约不变：

```js
DB.load() / DB.save()                       /* 内部已是「本机 + 云端合并 / 落盘 + 待传队列」 */
doParse(原话) / doParseAsync(原话)          /* 结构不变，凌晨 0~4 点规则已在内 */
SYNC.now() / SYNC.state()
```

本版新增一个原生契约（第 ④ 节用）：

```js
AppBridge.setBarsDark(bool)   /* 网页 → 原生：状态栏/手势条图标用深色(true)还是浅色(false) */
```

## 4. 功能需求清单

| 编号 | 需求 | 验收标准 | 复杂度 |
|---|---|---|---|
| **FR-401** | **在线更新** | 【检查更新】真去查 `version.json`：已是最新 → 显示版本号 + 检查时间；有新版本 → 显示版本号 + 更新说明 +【下载并安装】；APK 走 MediaStore 落盘后跳系统安装向导；网页端打开时提示"网页版随 index.html 更新，无版本概念" | 中 |
| **FR-402** | **自定义背景图** | 「我的 → 自定义背景图」选本地图片 → canvas 压缩（最长边 1080 / JPEG 0.75）→ 存本机；两个域各一张，切域跟着换；可恢复默认；**图片不上云、不进任何导出文件** | 中 |
| **FR-403** | **状态栏图标动态适配** | 换背景图后采样图片平均亮度：偏暗 → 通知原生用浅色图标，偏亮 → 深色图标；默认主题（无图）恒深色；切域 / 开关 App 时状态不丢 | 低 |
| **FR-404** | **回收站自动清理** | 启动时扫 `deletedAt`，超过 30 天的真删；删前 toast 告知数量；每月最多扫一次（记 `lastPurge`），不每次启动都扫 | 低 |
| **FR-405** | **云端加密（AES-GCM）** | 配云同步时可选开/关（默认**开**）：push 前用口令派生密钥（PBKDF2 同参数）加密 payload，pull 后解密；云端数据带 `enc` 版本标记；**解密失败不崩、不清本机**，弹窗说明"口令不对或云端是旧版未加密数据"；口令不明文进日志 | 高 |
| **FR-406** | **搜索与筛选** | 「记一笔」顶部加搜索框：标题/备注关键词实时过滤；筛选行：象限 / 分类 / 域 / 状态（未完成/已完成/逾期）；清空一步还原；纯内存计算，不落库 | 中 |

## 5. 分步开发清单（按依赖顺序，每步可单独验证）

### S1 · 在线更新（FR-401）　复杂度：中

1. `version.json` 放到 §11 Q1 定的公开地址，字段 `{version, apkUrl, notes}`。
2. 网页侧 `UPD.check()`：fetch 一次（5 秒超时 + try/catch，失败静默，遵守规则 13）；
   比对本机版本（`AppBridge.getVersionName()` 或 `APPVER`）。
3. 「我的 → 检查更新」改为真检查：最新 → 显示"已是最新（x.y）· 刚检查了"；有新版 →
   显示版本号 + notes +【下载并安装】。
4. 下载：`fetch(apkUrl)` → ArrayBuffer → 分块走现有 `AppBridge.writeBegin/writeChunk/writeEnd`
   落进「下载 / 待办清单」→ 跳系统安装向导（`Intent.ACTION_VIEW` + FileProvider 或
   MediaStore uri + `REQUEST_INSTALL_PACKAGES`——**二选一，先试 MediaStore uri，不行再加 FileProvider**）。
5. 网页端（非 app-mode）：按钮点击后提示"网页版随 index.html 更新"。

### S2 · 自定义背景图 + 状态栏动态适配（FR-402/403）　复杂度：中

1. 「更换图片」接文件选择器（复用导入备份同款 `<input type=file>` 通路）。
2. canvas 压缩：最长边 1080、`image/jpeg` 0.75 → dataURL；存 `DB`（新增 `bg.work` / `bg.life`）。
3. 渲染：`.phone` 背景 = dataURL（`background-size:cover`）+ 一层浅色遮罩保证卡片可读；
   两个域各一张；「恢复默认」删字段。
4. **容量兜底**：压缩后仍超 ~1.5MB 或 localStorage 写入抛错 → 提示"这张图太大，换张小一点的"，
   不崩不丢数据（§10 R1）。
5. **状态栏动态适配**：网页侧把图画到离屏 canvas 采样平均亮度 →
   `AppBridge.setBarsDark(亮→true / 暗→false)`；无图时恒 `true`；
   `MainActivity.setSystemBarIconsDark` 改为可被网页驱动（保留 onCreate 的默认深色）。
6. 验证：`apk-mode-check.js` 加一条——注入一张暗色 dataURL，断言 `AppBridge.setBarsDark(false)`
   被调用（用 JS 打桩记录调用）；再换亮图断言 `true`。

### S3 · 回收站自动清理（FR-404）　复杂度：低

1. `DB` 加 `lastPurge`（YYYY-MM-DD）；启动时（`init()` 内）当月未扫过才扫。
2. 扫：`t.deleted && now - t.deletedAt > 30 天` → 真删（不是软删标记）。
3. 删前 toast"回收站清理了 N 条（超过 30 天）"；一条没有就静默。
4. 测试：`smoke.js` 加用例——造两条 `deletedAt` 31 天前的 + 一条 10 天前的，跑清理函数，
   断言只剩 10 天那条。

### S4 · 云端加密（FR-405）　复杂度：高

1. `CLOUD` 加 `enc` 能力：`enc.on`（配置项）、`enc.v=1`。
2. 密钥派生：`PBKDF2-SHA256(同步口令, 固定salt, 100k)` → AES-GCM 256 位密钥
   （与 `SYNC.sid()` 同参数，复用现成 WebCrypto 代码）。
3. push：`payload → JSON → UTF-8 → AES-GCM(iv 随机 12 字节) → {v:1, alg:'AES-GCM', iv, ct}`
   再上传；pull：检测到 `enc` 标记 → 解密 → 原 payload；**没有标记 → 按旧版明文处理**。
4. 解密失败（口令换了 / 数据损坏）→ **不清本机、不重传**，弹窗说明原因 + 给【仍以本机为准】。
5. UI：云同步配置页加「上传前加密」开关（默认开），旁注"口令只在你设备上派生密钥，
   口令本身与密钥都不上云"。
6. 兼容：老云端明文数据 → 首次 pull 正常（无标记走明文路径），下次 push 自动变加密。

### S5 · 搜索与筛选（FR-406）　复杂度：中

1. 「记一笔」顶部（固定切换栏下方）加搜索框：输入即过滤当前列表（标题 + 备注，§11 Q4）。
2. 筛选行（搜索框下方，可折叠）：象限四格 / 分类（当前域）/ 状态（未完成 / 已完成 / 逾期）。
3. 与现有排序规则叠加：筛选只做"过滤"，**不改排序**（规则 1）。
4. 空结果给一句"没有匹配的 · 清空搜索看看"；`Esc` 或点×清空。

## 6. 数据结构（V0.4 新增）

| 字段 / 结构 | 含义 |
|---|---|
| `bg.work` / `bg.life` | 背景图压缩后的 dataURL（**仅本机**，不进备份/配置码/云端） |
| `lastPurge` | 回收站上次自动清理日期（YYYY-MM-DD） |
| `enc` | 云同步加密开关与版本：`{on:true, v:1}`；云端行内标记 `{v:1, alg:'AES-GCM', iv, ct}` |
| `upd` | 【检查更新】上次检查时间（给"已是最新 · 刚检查了"用） |

## 7. 视觉规格（沿用 V0.3，不改）

- 背景图：`background-size:cover` + 一层 `rgba(255,255,255,.55)` 级浅色遮罩
  （生活域可用暖色遮罩），保证白底卡片和文字读得清——这是 FR-402 的验收一部分。
- 搜索框 / 筛选行样式沿用 `.inputbox` / `.segbar`，不引入新组件。
- 其余（四象限、Tab 胶囊、域切换器）一律不动。

## 8. 开发约定与踩过的坑（V0.3 §9 的 29 条全部继承，以下只列新增）

30. **图片进 localStorage 前必须压缩**：canvas 最长边 1080 + JPEG 0.75；写入 try/catch，
    超限提示换小图——**不许**让一张图把整个 DB 写爆（会连累待办数据存不进去）。
31. **网页 → 原生的新调用**统一走 `AppBridge`（`typeof AppBridge!=='undefined'` 判断），
    浏览器里自动降级为 no-op；新增方法要在 `MainActivity.Bridge` 里加 `@JavascriptInterface`。
32. **加密只用 WebCrypto**（AES-GCM + PBKDF2），不引第三方库；iv 每次随机，密文带版本标记，
    方便以后换算法。口令/密钥**禁止**进 `console`、备份文件、配置码。
33. **下载 APK 用现有分块落盘通路**（`writeBegin/writeChunk/writeEnd`），别一次性塞 Binder。
34. 每步做完跑 `cd tests && node <对应脚本>`；S2 必须跑 `apk-mode-check.js`（新增了打桩断言）。

## 9. 风险与取舍

| # | 风险 | 取舍 |
|---|---|---|
| R1 | 背景图 dataURL 把 localStorage（约 5MB）撑爆 | 压缩到 ≤1.5MB 目标 + 写入 try/catch + 超限提示换图；仍不够 → V0.5 再评估 IndexedDB（原生零依赖，但 DB 层要动，本版不碰） |
| R2 | 加密后旧云端明文数据/换口令后解密失败 | 密文带 `enc` 版本标记；无标记走明文兼容路径；解密失败只弹窗不清本机；换口令按 V0.3 口径弹窗二选一 |
| R3 | APK 安装要"未知来源"授权，引导流程长 | MediaStore 落盘后直接跳系统安装向导 + 一行说明；不做应用内自动安装（系统不允许） |
| R4 | `version.json` 地址挂了对更新无感 | 检查失败静默 + 「我的」页显示"没查到（刚试过）"，遵守规则 13 不弹错 |
| R5 | 搜索框占首屏高度，挤压输入框 | 搜索框默认收起为一行小搜索入口，点开才占高度（S5 细节，做时定） |
