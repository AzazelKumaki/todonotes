## 为什么要留这份

V0.3 要动云同步、云服务配置和存储层（localStorage → 云 + 本地双写），改动面很大。
留一份 V0.2 的完整快照，好处是：

1. **随时能对比** —— 改坏了可以退回来看 V0.2 当时是怎么跑的
2. **随时能演示** —— 不用从代码里翻，直接打开这个 html 就是 V0.2
3. **不被后续改动污染** —— 副本不动，永远是可用的

## V0.2 的一句话状态

## 恢复方式

需要退回 V0.2 时：把 `index.html` 覆盖回 `prototype/index.html` 即可；
APK 那份直接装回手机（**注意：卸载会清掉本机数据，先导出备份**）。
签名用的 `android/daiban.keystore`（口令 daiban2026）也要留着，否则出不了更新包。
