---

## 1. 一句话

**一个能真用起来的本地待办清单**：张嘴说一句就能记下、打开就知道先干什么，工作和生活分开管理。
数据存在你自己的浏览器里，关掉再打开还在。

---

## 2. 怎么打开

双击 `prototype/index.html`（或留档副本 `留档/V0.1-M1/index.html`），用 Chrome / Edge 打开即可。
**不需要装任何东西、不需要联网、不需要账号。**

> 手机上用：把文件传到安卓手机，用浏览器打开，加到主屏幕即可当 App 用（M2 会出正式 APK）。

---

## 3. 界面导览

底部三栏，打开默认落在第 ① 栏：

| 栏 | 内容 |
|---|---|
| **① 记一笔** | 上方输入框（**打开即聚焦**，可直接说/打字），下方是「逾期 + 今天」 |
| **② 日历** | 月历，可左右翻月；点某天看当天明细 |
| **③ 我的** | 设置：云服务配置、AI 服务配置、导出备份、回收站、背景图、分类管理、检查更新 |

顶部是**工作 / 生活切换器**（第 ①② 栏可点，第 ③ 栏灰色不可点 —— 设置与域无关）。

## 4. 功能清单（V0.1 已实现）

### 记一笔

- **打开即聚焦**，可直接打字；语音用**输入法自带的麦克风**（界面上没有麦克风按钮）
- 点右侧 **【✦】** 触发解析 → 输入框下方展开 5 行字段：标题 / 完成时间 / **轻重缓急** / 归属 / 分类
- **每一行都能点着改**；「轻重缓急」是**一个四象限选择器**，点一次就选中
- 三条路径都行：① 直接【保存】② ✦ 解析后再保存 ③ 手工填完再保存
- **填不全也没关系** —— 标题/时间/轻重缓急/归属 4 项没填全，就进收件箱，绝不丢

### 规则版解析能听懂什么

| 类型 | 例子 |
|---|---|
| 日期 | 今天 / 明天 / 后天 / 下周 / 下个月 |
| 时间 | `3点`、`下午3点`、`晚上8点`、`9点半`、`4点45` |
| 重要 | 提到「重要 / 关键 / 老板 / 考核 / 必须 / 要紧」 |
| 紧急 | 提到「急 / 尽快 / 马上 / 催 / 赶紧 / 临时 / 截止」 |
| 分类 | 从当前域已有分类里挑（不自造） |

**没提到的 = 不算**。它不会自作主张把一件事标成"重要"。

### 列表与手势

- **点条目任意位置 = 进详情页**
- **点最左边的小圆圈 = 标完成**（不跳转）
- 标记完成后**不消失**：整条转灰、加删除线、**排到当天最下面**，并显示**真实完成时刻**
- 排序：**置顶 → 逾期（里面再按轻重缓急）→ 四象限 → 已完成**
- 首屏**不折叠**，放不下就下滑

### 四象限颜色（只看颜色就知道轻重缓急）

| 颜色 | 含义 |
|---|---|
| 🔴 红 | 重要且紧急 · 马上做 |
| 🔵 蓝 | 重要不紧急 · 计划做 |
| 🟠 橙 | 紧急不重要 · 快速处理 |
| ⚪ 灰 | 不紧急不重要 · 有空再说 |

### 日历

- 可左右翻月，今天有标记
- 每格显示 `3●2○`：● 已完成、○ 未完成
- 红下划线 = 这天有逾期；灰底 = 这天有复盘
- 逾期项**只挂在它原定那天**，不会跟着跑到未来每一天

### 收件箱

- **跨域暂存区**：工作域、生活域右下角各一个入口，**进的是同一个**
- 解析不全的条目都在这里；填全 4 项点【保存】即归入某域
- 可一键重新解析；**你手动改过的重要/紧急不会被覆盖**

### 分类

- 工作、生活各预置 4 个，可新建（名称 / 颜色 / 符号）
- **长按可拖动排序**，选分类时也是这个顺序
- **删分类不删待办**，改为「未分类」

### 双域

- 工作域冷蓝、生活域暖珊瑚，视觉一眼可分
- 两域数据**完全隔离**，互不混入

### 数据存储

- 存在**浏览器的本地库**里（localStorage）
- 任何一次改动都会立即落盘，**关掉再打开还在**
- 想清空：浏览器设置 → 清除该站点数据（或换浏览器打开）

## 5. V0.1 不做的事（别以为坏了）

| 不做 | 说明 |
|---|---|
| **真 AI 解析** | 现在是本地规则版（关键词匹配），只听得懂上表那几类说法 |
| **每日复盘** | 日历里有这个位置，显示"配置 AI 后自动生成"，**不是坏了** |
| **AI 服务配置** | 页面还在，但标注"M1 暂不启用" |
| **云同步 / 多设备** | 纯本地，换设备不同步 |
| **导出备份** | 点了会弹窗说明，但**不产出真实文件** |
| **APK** | 手机先用浏览器打开 |
| **循环安排** | 入口在日历页，但还没做 |

---

## 6. 已知限制

1. **解析是关键词匹配**，说得太绕会听不懂 —— 听不懂就进收件箱，手动归类即可，**不会丢**
2. **数据只在这一个浏览器里**：换浏览器、清缓存会丢，M2 会出导出备份
3. **回收站的"30 天自动清理"目前只有文案**，实际不会自动清
4. **背景图页是占位**：【更换图片】目前只弹提示
5. 日历的"这天有复盘"灰底在 M1 不会出现（没有复盘数据）
