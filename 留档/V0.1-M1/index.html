可点的地方

• 一进来就是 A2：输入框聚焦，六项字段面板直接展开在下面
• 聚焦态三条路：直接【保存】→ 进收件箱 · 点 ✦ 解析后【保存】 · 手工填完【保存】
• 退出 A2 回 A1：点【再改改】、点输入框外任意处、或按 Esc
• 顶部「工作 / 生活」切换 → 整站配色 + 数据都变
• 记一笔：打字 → 点 ✦ 解析 → 面板展开 → 保存
• 列表中：点条目进详情 · 点左边圆圈只标完成
• 标完成后不会消失：整条转灰、象限色条转灰、排到当日最下方
• 日历格里的 3●2○ 会跟着勾选实时变；逾期数也同步减少
• 右下角圆形按钮 = 收件箱（配色跟着当前域变）
• 日历：点某天只显示那天自己的事（逾期项挂在它原定那天，不跟着跑到未来）
• 标完成会记下真实完成时刻：翻回它原定那天能看到「完成于 10月15日 22:31」
• 日历栏没有悬浮 + 号了 —— 点底部「记一笔」就是聚焦输入
• A2 / 详情页：每个字段整行都能点 · 选日期会弹出月历直接点，还能填时间
• 日历页「🔁 循环安排」：可设每周 / 每月 / 每隔 N 天，属性照样记
• 收件箱：点圆圈直接标完成；点条目 → 右上角 ✦ 单条解析 → 【保存】归类
• 分类管理：整行可点编辑 · 长按可拖动排序（顺序在选择时也生效）· 自定义颜色和符号
• 分类器色作用在淡色底衬 + 左侧竖条上（emoji 本身保持原色，不突兀）
• 选时间用两个下拉（点 / 分），不用手打
• 我的：点顶部「云同步」卡片 → 就是云服务配置（唯一入口）
• 导出备份 / 检查更新 → 会弹窗告诉你结果
• 回收站可恢复 · 自定义背景图可分别换两个域
• 本地自动备份没有入口：每次打开自动存本机
